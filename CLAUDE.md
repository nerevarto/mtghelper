# mtghelper

"What can I cast?" for MTG sets. Enter your untapped mana sources; the grid filters to
exactly what that mana can pay for.

React 19 + Vite 7 + plain CSS + Firebase Hosting. No Firestore, no Auth, no `firebase`
dep, no `.env` — all card data is static and all user state is per-device localStorage.
Sibling project `E:\d2runtracker` shares the stack; follow its conventions.

## Commands

```
npm run dev          vite dev server
npm run build        -> dist/
npm run fetch-cards  regenerate src/data/sets/ from Scryfall (see SETS in the script)
npm run fetch-cards -- tla   process specific set codes instead
firebase deploy      needs your authenticated CLI
```

## Layout

```
scripts/fetch-cards.mjs   Scryfall -> src/data/sets/<code>.js + index.js manifest
src/lib/manaCost.js       parseManaCost(str) -> { generic, pips[], hasX } | null
src/lib/manaPool.js       SOURCE_PRODUCES, emptyPool, poolTotal, normalizePool
src/lib/solver.js         evaluate(pool, cost) -> { ok, maxX }; evaluateCard for faces
src/lib/parsePoolText.js  parsePoolText(str) -> { pool, unparsed[] }; formatPool(pool)
src/hooks/useCardSet.js   dynamic-imports the active set, caches in a module-level Map
src/App.jsx               owns all shared state; ALL filtering/sorting in one useMemo
```

`App.jsx` renders `SetPicker`, `ManaPool`, `FilterBar`, `CardGrid` as direct children.
Default-exported function components, props drilled one level, `on*` callback naming,
no context/reducers/routing/TypeScript. Local imports carry their extension so
`src/lib/*` runs under plain Node.

## Solver — do not improvise

A cost is payable iff **both**:

1. A bipartite matching saturates every coloured pip (source kind *t* serves pip *p* iff
   `SOURCE_PRODUCES[t] ∩ p.opts ≠ ∅`, capacity `pool[t]`). Greedy counting is wrong —
   it gets `{W}{W}` from `WU + RW` wrong.
2. `poolTotal(pool) >= generic + pips.length`. Sufficient because *every* source kind
   pays generic, so only the leftover count matters once colours are satisfied.

Generic-hybrid pips (`{2/W}`) enumerate all `2^k` colour-vs-generic splits; `ok` is true
if any split works, `maxX` is the max spare over the **feasible** splits only.

Symbol handling: `{X}`/`{Y}`/`{Z}` counted as 0 (`hasX` flagged); `{W/P}` phyrexian
skipped entirely — it must NOT become a pip or it inflates `pips.length`; `{S}` snow
counted as generic (**over-permissive approximation**, no snow source in the UI); `{C}`
payable only by a Colorless source, never by `ANY`.

`parseManaCost('')` → `null` (no castable cost). `parseManaCost('{0}')` →
`{ generic: 0, pips: [] }` — castable with an empty pool. That distinction matters.

Multi-face cards carry `"{W} // {1}{W}"` at the top level, so `card.faces` is
authoritative whenever it exists. Castable iff any face is; sort key stays the top-level
`cmc` even when only the adventure half is castable (accepted simplification).

Verified by fuzzing against a brute-force reference (270k cases, 0 mismatches). If you
change the solver, re-run that check.

## Behaviour worth knowing

- **Empty pool is a UI bypass, not a solver result.** `poolTotal === 0` skips the mana
  filter entirely so the grid doubles as a set browser. The solver correctly returns 0.
- **Pool text is not cost notation.** `2W` means two white sources, not `{2}{W}`.
  Pairs need a slash: `w/u` is one dual source, `wu` is one white plus one blue.
- **Pool object is the single source of truth**; the text box holds its own draft.
  Typing reparses and leaves the draft as typed; a stepper click regenerates the draft
  via `formatPool()`, which canonicalises the text and drops unparseable fragments.
- **Lands are excluded from the dataset** (you play them, you don't cast them). Dual
  *sources* in the mana UI are hardcoded in `manaPool.js`, decoupled from land *cards*.
- **Unticking every chip in a group means "no constraint"**, not "match nothing", so the
  grid can't be emptied by a misclick. `[]` in `filters` means all-on.
- Chip options and counts are derived from the loaded set, so a set bringing
  Planeswalker or Battle needs no code change. Each group's counts are measured against
  everything except itself.

## Adding a set

Add the code to `SETS` in `scripts/fetch-cards.mjs`, run `npm run fetch-cards`. The
manifest is regenerated by merging, so other sets' entries survive. Nothing else changes.
